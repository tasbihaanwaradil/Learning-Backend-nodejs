npm init
→ To initialize a Node.js project and create the package.json file.

npm init -y
→ To initialize a Node.js project with default settings automatically.

npm i express mongoose dotenv
→ To install Express, Mongoose, and dotenv packages.


node index.js
→ To run the index.js file using Node.js.


npm i -g nodemon
→ To install Nodemon globally.


npx nodemon
→ To run the project using Nodemon.

Nodemon
→ Automatically restarts the Node.js application when file changes are detected.

Remember: node index.js runs the file normally, while npx nodemon is useful during development because it automatically restarts the server after changes.

Quick Flow

Create Project
     ↓
npm init -y
     ↓
Install Packages
     ↓
npm i express mongoose dotenv
     ↓
Run Normally
     ↓
node index.js
     ↓
Or use Nodemon
     ↓
npx nodemon
